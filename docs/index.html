FAQ

常见问题

Windows 提示 SmartScreen 怎么办？

应用尚未购买商业代码签名证书，可能出现提示。请确认安装包来自本站跳转的 GitHub Release，并用同目录的 SHA256 文件校验后运行。

安装包会不会自动更新？

会。客户端会从 VocFlow 云服务检查新版本，并在下载后完成校验与安装；也可以从 GitHub Release 手动下载最新版。

哪些功能需要联网？

在线更新和大模型分析需要网络；学习记录、词库和个人数据只保存在本机，已经打开的学习资料可以离线阅读。
