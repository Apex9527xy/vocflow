FAQ

常见问题

iPhone 如何安装未签名 IPA？

在电脑安装爱思助手，连接 iPhone，使用自己的 Apple ID 对下载的 IPA 进行签名后安装。免费 Apple ID 的签名通常约 7 天到期，到期后需要重新签名；不愿重签可直接使用页面中的 PWA。

Android 提示未知来源或 Play Protect 怎么办？

VocFlow 通过 GitHub Release 侧载分发，未上架应用商店。请确认安装包来自本站跳转的 GitHub Release，并先核对同目录的 SHA256 文件，再允许当前浏览器或文件管理器安装。

Windows 提示 SmartScreen 怎么办？

应用尚未购买商业代码签名证书，可能出现提示。请确认安装包来自本站跳转的 GitHub Release，并用 SHA256 文件校验后运行。

哪些功能会使用网络？

在线查词、翻译和大模型分析需要网络；学习记录、词库和个人设置保存在设备本地。本地 Ollama、文件夹监听和桌面 PDF 管理仍仅限 Windows。
